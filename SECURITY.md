| < 1.0   | :x:                |

## Reporting a Vulnerability

The security and integrity of this project is a top priority.

If you discover a security vulnerability or potential exploit within this application:

1. **Do not create a public issue** on GitHub.
2. Please send a detailed report via email to **h4ck3r.bomb@gmail.com** with:
   - A description of the vulnerability.
   - Steps to reproduce or a minimal proof of concept (PoC).
   - Potential impact and affected components.
3. You will receive an acknowledgment within 48 hours.
4. Once verified, a fix will be prepared and deployed before disclosure.

Thank you for practicing responsible disclosure and helping keep the community secure.
